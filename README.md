# 📂 Smart File Organizer

A desktop application built with **Python** and **CustomTkinter** that automatically organizes files into categorized folders based on their file extensions. 
The application also detects duplicate files, generates organization reports, and maintains activity logs through an easy-to-use graphical interface.

---

## ✨ Features

- 📁 Organize files into categories automatically
- 🖼️ Sort Images, Documents, Videos, Audio, Archives, Code, Programs, and Others
- 📄 Preview file distribution before organizing
- 📊 Display live file statistics
- 📈 Progress bar during organization
- 📑 Generate CSV organization reports
- 📝 Automatic logging of file operations
- 🔍 Duplicate file detection
- 🌙 Dark/Light Mode
- 🖥️ User-friendly CustomTkinter GUI

## 🚀 Installation

### Clone the repository

bash
git clone https://github.com/Crypt-Jazib/Smart-File-Organizer.git


### Navigate to the project

bash
cd Smart-File-Organizer


### Install dependencies

bash
pip install -r requirements.txt


### Run the application

bash
python main.py

---

## 📊 Report Generation

The application automatically generates a CSV report after organizing files.

Example:

Category         Count

Images           20
Documents        15
Videos            5
Audio             8
Archives          3
Code             12
Programs          2
Others            4
Duplicates        1

Total Files      70


---

## 📝 Logging

Every organization session is recorded in the `logs` folder with timestamps, allowing users to review previous operations.
